よくあるご質問

無料ですか?

無料です。作るのも、渡すのも、使うのもお金はかかりません。広告もありません。

登録やインストールは必要ですか?

いりません。ブラウザで開くだけで作れます。アカウントもパスワードもありません。

作ったアプリはどこに保存されますか?

あなたの端末(ブラウザ)の中だけです。このサイトのサーバーには送られません。ブラウザのデータを消すと一緒に消えるので、大事なものはリンクか HTML で手元に残してください。

人に渡したアプリの記録は、相手に見えますか?

見えません。リンクに入っているのはアプリの「作り」(名前・項目・色)だけで、チェックや記録はそれぞれの端末の中に別々に残ります。

スマホでも作れますか?

作れます。スマホでは画面下の「できあがりを見る」で、動いているアプリを確かめながら書きかえられます。

6つの型にないものは作れませんか?

いまは6種類です。「こんな型が欲しい」が集まったものから増やしていきます。その先では、型そのものを自分で設計できるようにする予定です。
